# Panomotion · 全景球面运动估计与运动分析播放器

把等距柱状（equirectangular）全景画面中的像素映射为单位球面方向，在相邻帧之间
估计**受几何支持的方向运动**，再用该运动把上一帧重投影到当前帧进行核查。

输出不是无解释的二维像素偏移，而是：

- 一对单位球面方向 `d₀ → d₁`（经纬度可查）；
- 世界系旋转向量 `ω`（Rodrigues 表示，单位为弧度/度）；
- 测地线弧长（度）与对真值的角度误差；
- 经度接缝两侧的弧长连续性、极区坐标基切换标记与异常提示。

## 图形入口（主要交付物）

```bash
pip install -e ".[test]"
python -m panomotion gui
# 浏览器打开 http://127.0.0.1:8765
```

也可以使用安装出的命令：`pano-player` 或 `panomotion`（不带子命令时同样进入图形界面）。

界面是零前端依赖的本地 Web 播放器（标准库 HTTP 服务 + Canvas2D 软件透视渲染）：

- **球面视图**：逐像素逆透视采样当前帧，可拖动旋转视角、滚轮缩放、点击任意点检查运动；
- **展开图视图**：与球面视图共享同一组球面方向、同一批轨迹和同一个选中态；
- 同一轨迹可同时出现在球面与展开图中，跨接缝自动断段、不画横穿整图的错误直线；
- 播放/暂停、帧对滑杆、0.5x/1x/2x 速度；原始帧 / 重投影 / 残差三种底图切换；
- 图层开关：估计方向、GT 方向、轨迹、经度接缝、极区标注、未支持匹配点；
- 结果区：总览指标、当前帧对球面位移、选中点/轨迹检查器、接缝连续性逐行表、
  异常列表（点击异常直接跳到对应帧对）、26 条轨迹列表；
- 视频区直接播放/下载：原始序列、GT 球面运动、估计球面运动、四联重投影检查与 GIF。

如果 `runs/` 下还没有结果，可点击右上角 **“重新合成并分析 Demo”**，
或运行下面的命令行合成。构建进度会实时显示在页面顶部。

## 命令行（仅作辅助）

```bash

```

## 球面几何约定

`W×H` 图中整数坐标按像素中心处理：

```
lon = (u + 0.5) / W · 2π − π
lat = π/2 − (v + 0.5) / H · π
d   = (cos lat · cos lon, sin lat, cos lat · sin lon)   # y 轴向上
```

- **局部切平面法**：每个网格节点建立安全正交切基 `(b1, b2)`，在切平面内做
  NCC 块匹配 + Lucas–Kanade 亚采样细化，再用指数映射换回世界方向。
  高纬（`|d_y| > 0.85`）自动从东/北基切换到参考轴基，避免经纬基退化。
- **世界系旋转向量**：`ω = θ · normalize(d₀ × d₁)`，恰好满足
  `d₁ = Rodrigues(ω, d₀)`。它不带经纬度奇点，可直接做全局 Kabsch/Wahba
  主旋转拟合、正则扩散与重投影。
- **经度接缝是邻接关系**：采样横坐标模 `W`；接缝两侧节点的真实间隔是一个网格
  步长的弧长，而不是约 360° 的经度差。接缝表用“把一侧的 ω 作用到另一侧源方向”
  的相互预测偏差核查连续性。
- **跨极点**：越过展开图上下边不是 clamp，而是极反射
  （`v′ = −v−1` 或 `2H−v−1`，并 `u += W/2`）。跨极轨迹会出现接近 180° 的
  朴素经度翻转，但测地线步长只有约 5°；界面同时呈现这两个数字并打“跨极点”标记。
- **极区感知的度量/正则**：误差统计按极区（|lat|≥75°）、接缝带（8°）、
  中低纬分区；指标斑块纯度用球面角环判定，而不是会在极区被拉长的 UV 方框。
  稠密 ω 场用接缝环绕的 Jacobi 扩散填补未支持节点，再以固定点逆映射重投影。

## 为什么不能直接用普通平面光流

展开图上同样的像素步长在高纬对应的角距离按 `cos lat` 收缩，平面正则会在极区
过度平滑或产生错误权重；跨接缝的相邻像素分列图像最外侧两列；跨极点时经纬度
位移直接发散。因此本项目只把 UV 当作存储/显示格式，匹配、误差、正则与连续性
全部在切平面或世界方向/旋转向量上完成，并且**不裁剪两极**——极区节点照常计算、
如实统计低支持率并由界面提示异常。

作为对照，`panomotion/baseline.py` 提供一个朴素平面 UV 块匹配基线
（clamp 采样、无接缝处理、像素搜索），报告中并列给出其全图/中低纬/极区/接缝
角度误差。seed=11 的 960×480 Demo 上的典型结果：

| 指标 | 球面方法 | 朴素平面基线 |
| --- | --- | --- |
| 纯斑块可信点角度误差中位 | ≈ 0.07° | 全图 ≈ 0.7° |
| 最差帧对 p95 | ≈ 0.23° | — |
| 极区误差中位 | ≈ 0.12° | ≈ 1.9° |
| 接缝带误差中位 | ≈ 0.04° | ≈ 2.5° |
| 接缝相互预测最大偏差 | ≈ 0.2° | — |
| polar-crosser 轨迹中位误差 | ≈ 0.17°（180° 经度翻转 / 5.2° 弧长） | — |
| seam-crosser 轨迹中位误差 | ≈ 0.02°（353° 朴素跳变 / 6.3° 弧长） | — |

数值随机器/版本可能有小幅波动；以 `runs/demo/report.json` 为准。

## 合成序列与真值

`panomotion/synth.py` 生成无缝球面程序纹理（方向求值，接缝与极点无人工边界）、
已知相机 `yaw/pitch/roll` 路径，以及两个自带朝向的局部物体：

- **polar-crosser**：轨迹在相机坐标中从北极两侧跨过，专门暴露极点奇点；
- **seam-crosser**：越过 ±180° 经度接缝，专门验证接缝邻接。

背景与每个物体都有精确的逐帧旋转矩阵，`gt_targets()` 给出每个源方向的真值目标
方向，因此角度误差、重投影 PSNR、轨迹误差都可直接计算。

## 产物结构

一次运行写入 `runs/<name>/`：

```
meta.json  report.json  tracks.json
frames/frame_XXX.jpg        播放底图
reproj/reproj_XXX.jpg       逐帧重投影
error/error_XXX.jpg         残差热图
data/pair_XXX.json          前端契约：方向、ω 统计、分类、接缝、异常、GT 误差
videos/*.mp4                原始 / GT 运动 / 估计运动 / 重投影检查
videos/reprojection_check.gif
```

HTTP 服务仅暴露静态前端、上述 JSON API 与 `/artifacts/<run>/...`
（带目录穿越防护和视频 Range 支持）。
